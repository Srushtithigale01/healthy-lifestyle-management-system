# Healthy Lifestyle Management System

React + Vite frontend project for tracking water intake, exercise, sleep and healthy tasks.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown in the terminal.

## Production build
Run `npm run build`. Vite creates the production files in `dist/`.

## GitHub and Vercel
Push this project to GitHub and import the repository into Vercel. Use build command `npm run build` and output directory `dist`.

## Features
- Water, exercise and sleep trackers
- Add, complete and delete daily wellness tasks
- Browser localStorage persistence
- Responsive desktop and mobile layout

## Limitations
This is a frontend-only educational project. It does not include remote APIs, a server backend, user authentication or a server database.
